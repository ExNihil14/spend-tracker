# Changelog

Все заметные изменения проекта — по версиям. Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

## [0.2.0-beta] — 2026-09-24

Подготовка к публичному запуску: жизненный цикл данных, дизайн-волны, аудит и харденинг.
Тег `v0.2.0-beta` ставится при запуске (релизный контур — K1).

### Added

- **Импорт выписок**: адаптеры Сбер (включая email-CSV с «Дата совершения операции»), Т-Банк (13 колонок, MCC),
  ЮMoney; автоопределение банка; отчёт «добавлено/пропущено/подозрительно»; детектор дрейфа формата
  (`format_error` с просьбой прислать обезличенный образец).
- **Категоризация**: очередь «Подтвердить» с уровнями уверенности и клавиатурным триажем (j/k/Enter/s/1–9);
  bulk-одобрение с порогом («Одобрить все с уверенностью ≥ 60%»); калибровка порога (`spendtrack confidence`,
  Wilson-CI); `suggest-rules` — подсказки правил из ваших правок.
- **Бюджеты по категориям** (миграция v4): редактор в «Настройках», прогресс на дашборде — сортировка по риску
  и маркер темпа («прошло N% месяца»).
- **Подписки/рекурринги** и **дайджест недели** с аномалиями (крупные суммы, скачки цен, возможные дубли);
  CLI `recurring`/`digest`.
- **Жизненный цикл данных**: `spendtrack backup [--copy-to ПАПКА]` (снимок VACUUM INTO + внешняя копия
  с sha256-проверкой), `spendtrack anonymize` — обезличенный образец для issue; `doctor` (13 проверок) +
  `GET /health/data`; restore-drill.
- **Экспорт** CSV/XLSX (нативные типы, автофильтр, защита от formula-инъекций) — CLI и кнопка в UI.
- **LLM**: BYO (любой OpenAI-совместимый сервер) и локальный Ollama; бесплатные каналы — отдельный opt-in;
  по умолчанию ИИ **выключен** (ноль сетевых вызовов — тест «нулевой сети» в CI).
- **Установка**: `uv tool`/uvx + `install.ps1`/`install.sh`; Docker; команды `spendtrack serve` и `spendtrack paths`;
  user-dir для установленного режима (`%LOCALAPPDATA%`/XDG).
- **Мультивалютность** (схема v5): код валюты рядом с суммой; операции не в ₽ не попадают в рублёвые агрегаты
  и не склеиваются дедупом с рублёвыми.
- **UI/UX**: дизайн-система (токены, единые форматы сумм/месяцев, RU-имена категорий); импорт файлом
  с drag&drop; страница «Помощь»; лендинг и демо-режим (Codespaces); сервисный режим (systemd/launchd,
  Планировщик/NSSM).

### Changed

- Фрейм «ИИ выключен, пока вы сами не включите»: free-цепочка (OpenRouter :free + локальные прокси — явный
  `SPENDTRACK_ALLOW_LOCAL_LLM=1`, opt-in) вместо обязательного облака; офлайн-правила работают всегда.
- Порог авто-приёма — из конфига (0.9) и калибруется по вашим решениям (`spendtrack confidence`).
- README/лендинг/FAQ переписаны как «шлюз»: честные формулировки (Сбер — CSV по e-mail не у всех, XLS у физлиц
  не существует; полный e2e — Chromium, Firefox/WebKit — smoke); раздел «Обновление и удаление».
- Перки поддержки: «имя в README и CHANGELOG релиза (или анонимно), приоритет внимания к issue»; «ранний
  доступ» убран; фрейм — поддержка/услуги, не лицензия.

### Fixed

- Импорт: атомарность партии (rollback без «полу-строк»), дедуп реэкспорта со сдвигом, cp1251-файлы,
  мусорные даты больше не ломают страницы (P0), лимиты размера файла и сумм.
- Категоризация: импорт снова ставит `pending`/сохраняет `category_llm`; bulk-approve — whitelist таксономии;
  few-shot из правок.
- UI: протечка фильтра по дням, потеря месяца в ссылках, RU-подписи графиков, контрасты и фокус (WCAG),
  отсутствие горизонтальной прокрутки на 320px.
- `anonymize`: CRLF-выписки больше не превращаются в «\r\r\n»; предупреждение о неудаляемых датах/суммах.
- Производительность: месячные агрегаты по индексу, partial-индекс очереди, один `detect_recurring`
  на дашборд (на 50K строк: дашборд 2.75 с → 0.34 с).
- Валидация: невалидные `month`/`date`/`amount` → 422 вместо тихого мусора; escape описаний в htmx-ответах.

### Security

- Периметр: гейт Origin/Sec-Fetch-Site для state-changing запросов + `TrustedHostMiddleware`; строгий CSP
  `script-src 'self'` (без eval); `nosniff` и `no-referrer`.
- Supply chain: `uv lock --check`, pip-audit, Dependabot, GitHub Actions по commit SHA, `permissions: read`.
- Лимиты импорта (10 МБ), кламп confidence, лимит длины описания; ключи вне git (gitleaks в CI);
  `PRIVACY.md` (что и когда уходит наружу) и `SECURITY.md` (модель угроз, приватный канал для уязвимостей).

## [0.1.0] — 2026-09-14

Первая зафиксированная версия: ядро трекера работает, UI готов к реальному использованию.
*(Историческая запись: цифры тестов и LLM-цепочка — на момент 0.1.0; актуальное состояние — в 0.2.0-beta.)*

### Added

- Ядро: SQLite-хранилище (WAL), fingerprint-дедупликация импорта, LLM-категоризация с фолбэками (FreeLLMAPI → OpenRouter → DeepSeek через abacus-web → оффлайн-правила), CSV-импорт с адаптерами банков, отчеты по категориям, CLI.
- API: FastAPI, JSON + form-urlencoded, HX-ветка для htmx; эндпоинты транзакций, категорий, экспорта, pending-count.
- UI: htmx + Tailwind, списки с фильтрами по URL (hx-push-url), дашборды Chart.js, форма добавления, индикаторы.
- Качество: 44 теста pytest (оффлайн, без LLM), perf-маркер с JSON-отчетом, ruff clean.
- Окружение: uv/pyproject, .env.example, git trunk-based, публичный GitHub main с защитой.

### Changed

- Переход с TemplateResponse на контекст-локальное окружение для htmx (3.x совместимость).
- Модельный роутинг: OpenRouter `:free` как основной agentic-канал; abacus-web DeepSeek для анализа.

### Removed

- Секреты из .env.example (значения заменены пустыми/плейсхолдерами).

### Security

- Проверка git-истории перед публикацией на секреты; данные (`data/`) и ключи вне git.
